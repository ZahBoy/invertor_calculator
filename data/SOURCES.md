# Дані: інвертори на українському ринку

Зібрано 14.11.2026 з публічних сторінок інтернет-магазинів (ціни, характеристики) + вручну зібрані позиції з 13.11.2026.

## Файли

| Файл               | Що всередині                                                                         |
| ------------------ | ------------------------------------------------------------------------------------ |
| `inverters.csv`    | Усі пропозиції (543 рядки), один рядок = один товар в одному магазині                |
| `Invertor_24V.csv` | Інвертори на АКБ 24 В (90 рядків) у форматі демо-калькулятора: ті самі 4 колонки, що й у ручному файлі; трифазні позначені «(3 фази)» в назві |
| `Invertor_48V.csv` | Те саме для 48 В (283 рядки)                                                         |

Роздільник `;`, кодування UTF-8 (з BOM, щоб Excel відкривав кирилицю).

## Колонки `inverters.csv`

| Колонка                                      | Значення                                                                                                 |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `brand`, `name`                              | бренд (порожньо, якщо продавець не вказав) і назва з сайту                                               |
| `power_w`                                    | номінальна потужність, Вт                                                                                |
| `battery_v`                                  | напруга АКБ: `12` / `24` / `48` / `HV` (високовольтні 150–1000 В) / `none` (мережеві без АКБ) / порожньо |
| `battery_v_source`                           | звідки напруга: `specs` (таблиця характеристик), `name` (з назви), `type` (мережевий), `manual`          |
| `phases`                                     | 1 або 3 (порожньо — невідомо)                                                                            |
| `type`                                       | `hybrid`, `off_grid`, `grid_tie`, `micro_inverter`, `inverter` (тип не вказано)                          |
| `price_uah`                                  | ціна, грн                                                                                                |
| `in_stock`                                   | `yes` / `no` / `preorder`                                                                                |
| `warranty_months`                            | гарантія виробника, міс (є у ~42% рядків)                                                                |
| `parallel`                                   | скільки штук можна з'єднати паралельно (`yes` — так, без числа)                                          |
| `peak_power_w`, `pv_max_w`, `efficiency_pct` | пікова потужність, макс. потужність панелей, ККД                                                         |
| `rating`, `reviews`                          | рейтинг і кількість відгуків на сайті магазину                                                           |
| `store`, `url`, `scraped_at`                 | магазин, посилання, дата збору                                                                           |

## Обмеження

- **Надійності в даних немає**: магазини її не публікують. Калькулятор просить ввести її вручну; `warranty_months` можна використати як підказку.
- Характеристики на use.com.ua заповнюють продавці, тож там бувають помилки. Явні помилки потужності (напр. «5» замість 5000 Вт) виправлено за назвою товару.
- Ціни — на день збору, без урахування знижок.
