**Класи програми**

Model

Зберігає основну інформацію про інвертор: його назву, потужність, ціну, джерело інформації, напругу та номер у базі.

Choice

Зберігає інформацію про вибраний варіант: назву моделі, кількість інверторів, ціну одного інвертора, надійність, потужність та загальні витрати.

Option

Зберігає результати розрахунків для вибраного варіанта: ймовірність відмови, фінансовий ризик, бюджет та інформацію про перевищення бюджету.

**Функції для роботи з числами**
1. parse_number()

Очищає введене значення від зайвих пробілів, слів «грн» і знака відсотка. Також замінює кому на крапку та перетворює текст на число. Потрібна для того, щоб програма могла використовувати введені значення в розрахунках.

2. parse_reliability()

Перевіряє значення надійності та переводить відсотки у формат від 0 до 1. Також перевіряє чи правильно введене значення. Потрібна для правильного розрахунку ймовірності відмови.

3. parse_power()

Знаходить цифри в записі потужності та перетворює їх на ціле число. Потрібна для того, щоб програма могла працювати з потужністю інверторів.

4. parse_price()

Перетворює ціну на ціле число. Якщо ціна відсутня або записана неправильно, повертає 0. Потрібна для подальших розрахунків вартості.

5. money()

Форматує суму грошей, додає пробіли між тисячами та позначення гривні. Потрібна для зручного відображення цін на сайті.

6. price_text()

Розділяє великі числа пробілами між тисячами. Використовується для того, щоб ціни було легше читати.

7. percent()

Переводить десяткове число у відсотки та додає знак %. Потрібна для відображення результатів розрахунків у відсотках.

**Функції для роботи з базою інверторів**

8. load_file()

Відкриває csv файл, зчитує інформацію про інвертори, зокрема їхні назви, потужність, ціни та джерела інформації. Потім зберігає ці дані у вигляді об’єктів. Потрібна для завантаження моделей із таблиць.

9. load_catalog()

Завантажує дві таблиці з інверторами на 24 В і 48 В, об’єднує їх в один список та присвоює кожній моделі окремий номер. Потрібна для створення загальної бази інверторів.

**Функції для роботи з потужністю**

10. power_band()

Визначає, до якого діапазону потужності належить інвертор. Наприклад, інвертор потужністю 6000 Вт належить до діапазону 6 кВт. Потрібна для розподілу моделей за потужністю.

11. band_label()

Створює текстову назву діапазону потужності, наприклад 5.0-6.0 кВт. Потрібна для відображення діапазонів на сайті.

12. in_band()

Перевіряє чи належить потужність інвертора до вибраного діапазону. Потрібна для відбору відповідних моделей.

13. models_for()

Знаходить усі моделі з потрібною напругою та потужністю, потім сортує їх за потужністю, ціною та назвою. Потрібна для показу користувачу відповідних інверторів.

14. bands_for()

Переглядає всі моделі, рахує їхню кількість у кожному діапазоні потужності та вибирає діапазон, який буде встановлений за замовчуванням. Потрібна для формування списку доступних діапазонів.

15. suggest()

Підбирає модель, загальна вартість якої найближча до бюджету користувача. Спочатку намагається знайти варіант, який не перевищує бюджет. Потрібна для автоматичного вибору моделі.


**Функції для математичних розрахунків**

16. reliability_at()

Розраховує, наскільки надійним буде один інвертор через певну кількість років. Потрібна для врахування зміни надійності з часом.

17. plain_p()

Перетворює число у зручний текстовий формат, залишаючи потрібну кількість знаків після коми. Потрібна для правильного відображення чисел у формулах.

18. failure_probability()

Розраховує ймовірність того, що всі вибрані інвертори одночасно вийдуть з ладу. Потрібна для визначення ймовірності повної відмови системи.

19. failure_formula()

Формує математичну формулу, за якою розраховується ймовірність відмови. Потрібна для того, щоб показати користувачу, як саме виконується розрахунок.

20. evaluate()

Розраховує ймовірність відмови та множить її на загальну вартість інверторів. Потрібна для визначення фінансового ризику кожного варіанта.

21. shown_options()

Перевіряє, чи не повторюються другий і третій варіанти з однаковою моделлю інвертора. Якщо вони однакові, залишає той, у якого менший ризик. Потрібна для уникнення повторів у результатах.

22. ranks()

Розподіляє результати за місцями: найкращий, проміжний і найгірший. Потрібна для зручного порівняння варіантів.

23. curve()

Розраховує значення надійності системи для різних проміжків часу. Потрібна для побудови графіка зміни надійності.

24. read_choice()

Отримує дані про вибраний варіант, перевіряє ціну та надійність і створює об’єкт із цією інформацією. Потрібна для підготовки даних до математичних розрахунків.

25. calculate()

Виконує основні розрахунки для всіх трьох варіантів, визначає їхній ризик, сортує результати та готує дані для графіка. Це основна функція, яка відповідає за порівняння варіантів

**Функції для відображення результатів**

26. result_block()

Формує блок із результатами розрахунків, де показуються кількість інверторів, ймовірність відмови, загальні витрати та фінансовий ризик. Потрібна для відображення результатів на сайті.

27. chart_svg()

Створює графік, який показує як змінюється надійність різних варіантів із часом. Потрібна для візуального порівняння інверторів.

28. options_html()

Створює список варіантів для вибору на сайті та позначає той, який уже вибраний. Потрібна для роботи випадаючих списків.

29. variant_rows()

Створює поля для кожного варіанта, де можна вибрати модель інвертора, вказати ціну та надійність. Також показує загальну вартість. Потрібна для формування форми порівняння.

**Функції для створення сторінок**

30. read()

Відкриває потрібний файл і зчитує весь його вміст. Потрібна для отримання інформації з HTML-шаблонів та інших файлів.

31. fill()

Знаходить спеціальні позначення в HTML-шаблоні та замінює їх на потрібні значення. Потрібна для автоматичного заповнення сторінок інформацією.

32. page()

Створює повну сторінку сайту, додаючи заголовок, основний вміст і навігацію. Потрібна для формування сторінок в одному стилі.

33. first()

Отримує перше значення за потрібним ключем із даних, які користувач відправив через форму. Якщо значення немає, повертає значення за замовчуванням. Потрібна для отримання введених даних.

34. render_index()

Обробляє параметри, які вибрав користувач, підбирає відповідні моделі, запускає розрахунки та формує головну сторінку калькулятора. Потрібна для забезпечення роботи основної сторінки сайту.

35. render_help()

Зчитує файл із поясненнями та відображає його вміст на сторінці допомоги. Потрібна для того, щоб користувач міг ознайомитися з інструкцією.
